エッジ関数は、Cloudflare Workers や Fastly Compute がそうするように、ユーザーの隣の CDN で小さなハンドラーを動かします。

## どこに置くか

- ユーザーがオリジンから遠く、ハンドラーが小さいときに置きます。リダイレクト、ヘッダーの書き換え、キャッシュからの読み取り、個人向けのページなどです。シリーズ C で[エッジコンピューティング](/research/edge-compute)として、コンテンツ配信のあとに 80,000 ◇ でアンロックします。
- アップロードの画像リサイズ、エクスポート、ログインのパスワードハッシュなど、CPU の重い種別には省きます。それらはアプリサーバーの仕事です。
- 別のリージョンのユーザーが必要とするときはこれを複製します。1 つのエッジ関数は自分のリージョンにしかサービスを提供しないからです。

## 仕組み

自分のリージョンにしかサービスを提供しません。そこにいるユーザーはオリジンまでの往復ではなく 5 ms で届き、別のリージョンのユーザーはやはりその往復を払います。すべてのリクエスト種別に[アプリサーバー](/components/server)と同じように答え、それが行うバックエンド呼び出しに変えます。コールドスタートはほとんど気になりません。V8 のアイソレートは 5 ms 未満で起動し、コンテナや JVM の数秒とは比べものです。

動いているエッジ関数は、[CDN](/components/cdn)が `read` に答える元になるエッジのキーバリューキャッシュも保持します。そのキャッシュは API 読み取りの 30% に答え、CDN だけでは 0% です。

リクエストごとに、[クラウドの請求](/design/09-economy#the-cloud-bill)の Requests の行で課金され、遊んでいる間は何もかかりません。

## 上限

エッジ関数にはインスタンスの種類も、選べるサイズもありません。代わりに 2 つの上限があります。

- **CPU。** 1 つのリクエストは 10 ms の CPU まで使えます。それを超えるとハンドラーは殺され、リクエストはタイムアウトとして失敗します。
- **メモリ。** ハンドラーは 128 MB のアイソレートで動き、小さなハンドラーとその応答は収まりますが、ワーキングセットは収まりません。

サービスのスタックで動くので、スタックはエッジへコンパイルできる必要があります。JavaScript と TypeScript、または WebAssembly にビルドした Rust と Go です。PHP、Ruby、Python、Java、C#、Elixir、Zig、Haskell のスタックはそこで拒否され、カードもそう表示します。

## どう壊れるか

- **CPU の上限。** 10 ms を超える CPU を要するリクエストは途中で殺されるので、アップロード、レポート、エクスポートはここには向きません。
- **スタック。** PHP で動く会社はエッジをまったく使えません。直し方はコンパイルできるスタックへの[マイグレーション](/design/08-team-and-velocity#migrations)で、2 つ目のエッジノードではありません。
- **データ層。** リクエストごとにデータベースを呼ぶハンドラーは、どのみち往復を払うので、ユーザーの 1 ホップを省くだけで、クエリは省けません。

### [証明書の期限切れ](/incidents/certificate)

- **兆候:** **証明書の期限切れ**のバナーが出て、エッジ関数を通るすべてのリクエストが、ほかの TLS ノードと同じく失敗します。
- **今すぐ:** バナーの**更新**をクリックします。
- **防ぐ:** [証明書の自動化](/research/cert-automation)をリサーチし、[シークレットと証明書](/components/pki)のノードを置きます。証明書が切れる前に更新します。

### [リージョン障害](/incidents/region)

- **兆候:** 1 つのリージョンのボードが灰色になり、そこにあるエッジ関数が落ちます。
- **今すぐ:** バナーで**フェイルオーバー**を押します。[マルチゾーン](/research/multi-az)と 2 つ目の開いたリージョンが必要で、最も近い別のリージョンでノードをコールドで、置き換え 1 回分の値段で立ち上げ直します。そうしなければインシデントが終わったときに戻ります。カタログでは 180 シミュレーション秒、エラーバジェットが効いてからは 60 秒です。
- **防ぐ:** [マルチリージョン](/research/multi-region)をリサーチし、2 つ目のリージョンにコピーを保ち、[GeoDNS](/research/geo-dns)を追加してユーザーをそこへ送ります。

## ヒント

- CDN と組にすると、CDN がキャッシュできないものをエッジが返し、残りを CDN が返します。
- ハンドラーは小さく保ちます。アイソレートの上限は、回避すべきバグではなく設計上の制約として扱います。
