WAF は、OWASP Core Rule Set を備えた ModSecurity のような Webアプリケーションファイアウォールを指します。

## どこに置くか

- ボットがトラフィックの大きな割合を占めてアプリサーバーに負荷をかけるとき、またはボットでログインが急増するときに置きます。[Webアプリケーションファイアウォール](/research/waf)でアンロックします。
- 攻撃下モードは DDoS が続く間だけオンにします。

[ボット](/sandboxes/bots)のサンドボックスがその症状を示します。

::Sandbox{id="bots"}

## 仕組み

アプリサーバーの手前に置きます。すべてのリクエスト種別を受け、通したものを先へ送ります。ボットの一部を遮断し、それと一緒に実際のユーザーもより少ない割合で遮断します。遮断されたユーザーは `blocked` で失敗します。[WAF（Webアプリケーションファイアウォール）](/glossary/waf-web-application-firewall)を参照してください。

サイズを 1 段上げるごとに容量が 2 倍になります。すべてのゾーンにまたがります。

## オプション

::Options{id="waf"}

- **パラノイア**: ルールがどれだけ厳しく見るか。段を上げるほど多くのボットを遮断し、実際のユーザーもより多く遮断し、リクエストあたりの CPU が増えるので、WAF が処理できるトラフィックは減ります。
- **攻撃下**: オンの間はすべてのリクエストにチャレンジを課します。ごみのほぼすべてを遮断し、実際のユーザーも一部遮断し、レイテンシを加えます。洪水が終わったらオフにします。

## どう壊れるか

- 過負荷になると、リクエストがアプリサーバーに届く前に捨てます。パラノイアの段が高いとこれが早く起きます。
- 高い段は実際のユーザーを遮断し、売上を損ないます。

WAF がないと、[ボット急増](/incidents/bot-surge)、[クレデンシャルスタッフィング](/incidents/stuffing)、[DDoS](/incidents/ddos)がより強く、より頻繁に襲います。

### [正規表現バックトラッキング](/incidents/regex)

- **兆候:** インスペクタに「ルールがバックトラックしています。CPU が 100% です。」と出ます。すべての WAF が CPU を使い果たします。[ReDoS（正規表現によるサービス拒否）](/glossary/redos-regular-expression-denial-of-service)を参照してください。
- **今すぐ:** **ルールを無効化**を押します。
- **防ぐ:** 防ぐリサーチはありません。WAF は常に悪いルールの危険を抱えます。

### [DDoS](/incidents/ddos)

- **兆候:** インスペクタに「ごみのトラフィックの洪水です。」と出て、需要がごみの 50 倍になります。
- **今すぐ:** WAF の**攻撃下**を押します。すべてのリクエストにチャレンジを課し、レイテンシを加えます。
- **防ぐ:** エッジに WAF と CDN を保ちます。[Webアプリケーションファイアウォール](/research/waf)と[コンテンツ配信](/research/cdn)です。終わったら攻撃下モードをオフにします。

### [インスタンス障害](/incidents/instance)

- **兆候:** WAF のカードが灰色になり、インスペクタに「この VM の下のホストが死にました。請求は続きます。」と出て、そこへ送ったリクエストは行き場所を失います。
- **今すぐ:** インスペクタの**置き換え**を押し、値段を払います。コールドで戻ります。
- **防ぐ:** 2 つ目のコピーを動かします。[ロードバランシング](/research/load-balancing)がコピーをロードバランサーの後ろに置き、[ヘルスチェック](/research/health-checks)が死んだホストを飛ばします。

### [リージョン障害](/incidents/region)

- **兆候:** 1 つのリージョンのすべてのノードが一斉に灰色になり、そのリージョンのボードも一緒に灰色になります。
- **今すぐ:** バナーで**フェイルオーバー**を押します。[マルチゾーン](/research/multi-az)と 2 つ目の開いたリージョンが必要で、最も近い別のリージョンでノードをコールドで、置き換え 1 回分の値段で立ち上げ直します。そうしなければインシデントが終わったときに戻ります。カタログでは 180 シミュレーション秒、エラーバジェットが効いてからは 60 秒です。
- **防ぐ:** [マルチリージョン](/research/multi-region)と [GeoDNS](/research/geo-dns)をリサーチし、2 つ目のリージョンでコピーを動かします。

## ヒント

- 既定の段から始め、ボットがまだ通るときだけ上げます。
- DDoS が終わったら攻撃下モードをオフにします。
