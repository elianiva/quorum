メールは `I`、ダッシュボードは `D` で開きます。ページャーと地域のタブはボードの上にあるので、開くことはありません。

## 受信箱

受信箱はボードの右下のボタンで、バッジが未読のメールを数えます。判断を待つメッセージがあるとバッジが赤くなります。`I` でパネルを開き、`Esc` で閉じます。

![左にフォルダ、右に開いたメッセージがある受信箱](/play/mail.png)

上のフォルダを見ます。**要対応**、**参考**、**スパム**、**ゴミ箱**です。要対応には、何かを変えるボタンがあり、まだ答えのないメールが入ります。参考には残りが入ります。

各行は差出人の色付きバッジ、差出人、時刻、件名を示します。バッジの形と記号が差出人の種類を告げます。クラウドのプロバイダ、監視の道具、ベンダー、チームメイト、投資家などです。色は差出人が模した会社から来るので、種類のラベルも読みます。色だけが手がかりになることはありません。

1つの差出人からの1つの話題についてのメールは**スレッド**で、繰り返しはそれに加わって新しい行ではなく件数を示します。スレッドは原因が消えると解決し、記録としては残ります。

メッセージに答えるには、次のようにします。

1. 行を選択します。右に読み物が開きます。
2. 本文を読み、その下のボタンを読みます。**ボードで表示**はメッセージが扱うノードを選択します。
3. 行動のボタンをクリックするか、その番号キーを押します。`1` が1つ目のボタン、`2` が2つ目、と続きます。

番号キーは読んでいないメッセージでもボタンを発火し、そのボタンはリサイズや調達のような本物の行動を走らせるので、先に読みます。

| キー  | 受信箱での効果                         |
| ----- | -------------------------------------- |
| `J`   | 次のメッセージ                         |
| `K`   | 前のメッセージ                         |
| `E`   | 削除、またはゴミ箱から戻す             |
| `S`   | スパムとして報告、またはスパムではない |
| `Esc` | 受信箱を閉じる                         |

スパムは本物の差出人が書かないメールです。開くのは無料ですが、罠に行動すると代償があります。8件を超えるスレッドが未読になると、古い参考のスレッドが1つの**ダイジェスト**の行にまとまります。何も失われず、ダイジェストが1件ずつ並べます。

## ダッシュボード

ダッシュボードは `metrics` をリサーチしたあと、`D` で開きます。設計を時間の上で示す、全画面のグラフの集まりです。

![期間のボタン、スイッチ、黄金のシグナルがあるダッシュボード](/play/dashboard.png)

上から読みます。

1. **期間。** **1h**、**6h**、**1d**、**7d**、**30d**を選びます。これはカレンダーの時間なので、1時間は 1× の速度でおよそ1分のプレイです。
2. **変数。** 選択欄が、すべてのグラフをリクエスト種別で、複数あるときはサービスとリージョンで絞ります。
3. **比較**は各時系列に昨日の薄い線を描きます。
4. **表**は各グラフをその値の表に変えます。
5. **注釈のスイッチ。** **設計の変更**、**デプロイ**、**インシデント**、**会社**、**リサーチ**は、それぞれすべての時系列に色付きの縦の印を描きます。印が線に混み合うときは1つをオフにします。

最初の行には黄金のシグナルが並びます。ユーザー、毎秒の資金、Apdex、最も熱いノード、エラー率、p99です。その下にコンポーネントごとの行、そのあとに会社とインシデントの行があります。線がなぜ曲がったかを見るには、スイッチを入れて、曲がりのすぐ前の印を探します。レイテンシのグラフは[p99 とテールレイテンシを読む](/guides/read-p99)を読んでください。

可視性のリサーチごとにグラフが増え、リサーチのないグラフはどれが必要かを告げます。

## 用語集

ゲームは各エンジニアリング用語を、この wiki の[用語集](/glossary)のページへリンクします。ツールバーの本のボタンは、最初のトレードオフのカードに出会ったあとにハブを開きます。

トレードオフのカードの用語のチップ、リサーチ項目の `?` のチップ、セキュリティ勧告の CVE id は、どれもそのページを新しいタブで開きます。セキュリティ勧告はハブの**セキュリティ**の下に並びます。

各ページは、その用語が仕事で何を意味し、Quorum で何をするかを、関連する用語と次に読む資料とともに示します。

## ページャーとインシデントの帯

アラートには `alerting` のリサーチが必要です。そのあと、ボードの上の帯に2つの知らせが載り、そのうち声が大きいのは1つだけです。

**インシデントの帯**が赤いのは、クリック1つでインシデントが終わるからです。インシデントの名前、重大度、止めるクリックを示します。同時に1つのインシデントを載せ、十字のボタンがインシデントの当たったノードを選択します。連鎖は帯の中に「放置されたスロークエリに続く」のような行を加えるので、2ページ目は2ページ目として読めます。

その下の**アラートのチップ**は、ルールが発火している間も静かなままです。ルールを数え、最初の症状を名指しし、2つのボタンを持ちます。チェックの印は発火中のすべてのルールを確認済みにし、どれかが消えるまでチップを件数に畳みます。**アラート**はダッシュボードのアラートの行を開きます。

![上の帯にある赤いインシデントの帯と静かなアラートのチップ](/play/pager.png)

調整はダッシュボードで行います。アラートの行には各ルールの3つのしきい値、ルールがいま読んでいる値、それがどれだけ続いたか、状態が並びます。狼少年を呼びすぎたルールはチップとその行に**無視**と出ます。そこで別のしきい値を選ぶと再びオンになります。

インシデントの帯はボタンを1つだけ持ち、示しているインシデントの1クリックの直しになります。

- **ロールバック**。不正デプロイで出ます。CI をリサーチするまで灰色です。
- **更新**、**リーダーを隔離**、**マイグレーションを中止**、**固定して再デプロイ**、**復元**、**再起動**、**ノードを再起動**、**フェイルオーバー**、**接続を制限**、**ログインを移す**。それぞれが対応するインシデントを終わらせます。

ポストモーテムはメールです。インシデントが終わるとチームメイトが何があったのか尋ね、そのメッセージに**提出**とその横のアクションアイテムが入ります。アクションアイテムを開いたままにすると、そのインシデントは2倍起こりやすくなります。

全体の流れは[最初のインシデント](/tutorials/first-incident)を読んでください。

## 地域のタブ

シリーズ C から、`multi-region` をリサーチすると**リージョン**の帯が上の帯に出ます。開いた各リージョンは NA や EU のような短い名前のタブです。クリックするとそのリージョンのボードが見えます。閉じたリージョンは「+ EU」と表示されます。クリックするとリージョンが開き、先にホバーすると価格が読めます。

infra-as-code をリサーチすると**ミラー**のボタンが帯に加わり、何を複製するかは[グローバルに展開する](/guides/go-global)が扱います。タブの琥珀色の点は、そのリージョンが複製元からずれたという意味です。
