カードをドラッグすると移動し、クリックすると選択し、`Shift` を押したままにすると複数を選択できます。移動と選択は無料で、売却は資金を返します。ここで設計の動作を変える操作はボックスだけです。データグループを作り、2つ以上の単一データベースをまとめて囲むとシャードに変わります。

## ノードをドラッグする

1. カードの本体を押してドラッグします。数ピクセル動かすとカードがポインタに付いてきます。
2. 離します。カードは8ピクセルのグリッドに乗ります。ほかのカードと重なる位置なら、最も近い空き位置へ滑ります。

リンクはカードに付いてきます。カード右端の青い出力ポートを押すと、移動ではなくリンクが始まります。これがよくある驚きなので、移動したいときはカードのタイトルか行をつかみます。[リンクでノードを配線する](/play/wire-nodes)がポートを扱います。

空き領域からの普通のドラッグは表示を動かし、空き領域からの `Shift` + ドラッグは代わりに選択ボックスを描きます。ホイールを回すとズームします。

## ノードを選択する

| 操作                                       | 結果                                                                                     |
| ------------------------------------------ | ---------------------------------------------------------------------------------------- |
| カードをクリック                           | ノードが1つ選択されます。右にインスペクタが開きます。                                    |
| `Shift` + カードをクリック                 | そのカードが選択に加わるか、選択から外れます。                                           |
| 空き領域で `Shift` + ドラッグ              | ボックスが描かれます。触れたカードがすべて選択になります。                               |
| `Shift` + `Ctrl`（または `Cmd`）+ ドラッグ | ボックスが選択に追加します。                                                             |
| `Shift` + `Alt` + ドラッグ                 | ボックスが選択から取り除きます。                                                         |
| `Ctrl`（または `Cmd`）+ `A`                | この地域のボードのすべてのノード。固定のノード（ユーザー、決済）と共有ノードは除きます。 |
| 空き領域をクリック、または `Esc`           | 選択が解除されます。                                                                     |

選択したまとまりには枠が付きます。選択中のカード、または枠の内側をドラッグすると、まとまりごと動きます。カードの普通のクリックはまとまりをその1ノードに置き換え、空き領域のクリックは選択を保たずに解除します。

## 選択バー

`Shift` の選択がある間、画面下の建設ドックの代わりにバーが出ます。会社でもサンドボックスでも同じです。**N 件選択**と表示され、そのあとに6つのアイコンボタンが並びます。

![ボード下部の選択バー。3つのノードが選択されています。](/play/selection-bar.png)

アイコンの行を見ます。各ボタンはホバーすると名前とキーを表示します。

| ボタン                     | キー     | 働き                                                                                                                   |
| -------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| **コピー**                 | `Ctrl+C` | ノードとその間のリンクをクリップボードに入れます。トースト: **3 ノードをコピーしました。**                             |
| **複製**                   | `Ctrl+D` | 選択のコピーを48ピクセル右下の最も近い空き位置に置きます。コピーごとに新しいノードとして支払います。                   |
| **ノードを囲む**           | なし     | 選択の周りに破線の枠を1つ描き、そのデータベースを1つのデータグループにします。同じノードでもう一度押すと枠が外れます。 |
| **売却**                   | `Delete` | 先に確認してから売ります。下を参照してください。                                                                       |
| **プレイブックとして保存** | なし     | 選択を、エグジットを越えて残るプレイブックとして保存します。トースト: **プレイブック 1 を保存しました: 3 ノード。**    |
| **選択を解除**             | `Esc`    | 選択を空にします。                                                                                                     |

`Ctrl+C`、`Ctrl+X`、`Ctrl+D` は、普通のクリックで開いた1つのノードにもバーなしで効きます。バー自体は `Shift` の選択を必要とします。普通のクリックは代わりにインスペクタを開くので、1つのノードをコピーするにはクリックの直後に `Ctrl+C` を押します。

## コピーと貼り付け

1. ノードを選択します。`Ctrl+C` を押します。トーストに**2 ノードをコピーしました。**と出ます。
2. `Ctrl+V` を押します。バーに**`クリックして <name> を配置 · Esc`**と出て、コピーがポインタに付いてきます。
3. コピーを置きたい場所のボードをクリックします。最も近い空き位置に置かれ、各コンポーネントの価格が資金から引かれます。

`Ctrl+X` はコピーと売却を一度に行います。コピーを置かずに捨てるには `Esc` を押します。

何も選択していないと、`Ctrl+C` は**先にコピーするノードを選択してください。**と言い、クリップボードが空なら `Ctrl+V` は**先にノードをコピーしてください。**と言います。

## キーボードで微移動する

`Shift` を押したまま矢印キーを押します。選択中のノード、または選択全体が16ピクセル動きます。ほかのカードの上に乗る移動なら、何も起きません。

`Shift` なしの矢印キーは別の働きをします。その方向で最も近いノードを選択します。マウスを使わずに設計をたどれます。

## 整列と表示の合わせ

- **役割ごとに整える**（`Shift+T`）は、地域のボードのすべてのノードを役割の列に並べ、そのあと表示を合わせます。動かすのはカードだけで、`Z` で元に戻せます。普通のドラッグや微移動は元に戻すの段階になりません。[Tidy がボードをどう並べるか](/explanation/tidy)がルールを示します。
- **ボードに合わせる**（`Shift+F`）は、すべてのノードが画面に入るようにズームと移動をします。カードは動きません。

どちらのボタンも右上のツールバーにあります。スマートフォンでは**その他**のメニューに入ります。

## 売却

売却は、そのコンポーネントの最後の1つの配置に払った額の半分を返します。

1. ノードを選択し、`Delete`（または `Backspace`）を押すか、選択バーかインスペクタの**売却**を押します。
2. バーに**2 ノードを $120 で売却しますか？**と**売却**、**キャンセル**が出ます。ノードはまだ消えていません。
3. `Enter` か**売却**を押して確定します。`Esc` か**キャンセル**なら何も失いません。

売ったノードのリンクも一緒に消えます。`Z` でノードが戻り、30秒以内なら元に戻すが同じ資金を返します。確認バーが先に尋ねるのは、売却が誤って起きやすいからで、その元に戻すが2回目の機会です。

固定のノードは売れません。ユーザーを選択して `Delete` を押すと、トーストに**ユーザーは残ります。**と出ます。決済も同じです。混ざった選択では固定のノードが残り、ほかが売られます。

## 試してみる

目標: カードを左から右へ1列に並べ、どの2つも触れないようにします。そのあと `Shift` とクリックで2つを選択し、`Shift` を押したまま空き領域からボックスをドラッグして残りを選択します。`Shift` なしのドラッグは表示を動かすだけです。
