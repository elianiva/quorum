コンポーネントを置くには、建設ドックでグループを開き、コンポーネントを選び、ボードをクリックします。ノードがポインタの下に現れ、会社がその価格を払います。

![Edge グループを開いた建設ドック。](/play/dock.png)

_グループのアイコンの上に開いた一覧を見ます。各行に名前、それについての1行、価格、番号キーが出ます。_

## ノードを置く

1. 画面下の建設ドックでグループのアイコンを探します。1つにホバーすると、**データ (3)** のように名前と番号が読めます。
2. グループをクリックするか、その番号キーを押します。ドックの上にコンポーネントの一覧が開きます。
3. 行を読みます。各行にコンポーネントの名前、それについての短い1行、価格が出ます。赤い価格は、いまは払えないという意味です。鍵の付いた行は、それを開くリサーチを示します。
4. 行をクリックするか、その番号キーを押します。一覧が閉じます。ドックにはコンポーネントの名前、**ボードをクリック**、X ボタンが出ます。
5. ボードの空いている場所をクリックします。カードがポインタを中心に現れ、HUD の資金の行が価格の分だけ下がります。
6. 画面の右側を見ます。置くと選択も兼ねるので、インスペクタが新しいノードで開きます。

5 のクリックの代わりに `Enter` を押すと、部品は次の空き位置に落ちます。これがキーボードでの置き方です。

置き間違いはその場で直すのが一番安くつきます。30秒以内に `Z` を押せば返金は正確です。[時計、元に戻す、セーブ](/play/clock-undo-saves)が説明します。

置いたノードはまだ何にもつながっていないので、資金を食い、リンクを足すまでトラフィックを運びません。[リンクでノードを配線する](/play/wire-nodes)がドラッグを扱います。

::Component{id="database"}

_置いた直後にボードで見えるデータベース。まだ何も配線されていません。_

## 1回の選択で1つの部品

手に持った部品は1回の配置で使われるので、2つ目のデータベースを置くにはドックでもう一度選びます。これは意図的です。ボードのうっかりクリックが何かを買うことはなく、2度目のクリックが2つ目のノードを置くこともありません。

置かずに部品を戻すには、`Esc` を押すかドックの X ボタンをクリックします。

## 場所が埋まっているとき

空いている場所ならどこでもクリックできます。場所がカードと重なると、ノードは最も近い空き場所へ滑ります。あとでドラッグできます。[移動、選択、コピー、売却](/play/move-and-select)を参照してください。

## ゲームが断るとき

断りはトーストで出て、部品は手に残ります。空いている場所をクリックするか `Esc` を押します。

| メッセージ                                                                | 原因                                                                               |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `<Component> は $<price> かかります。`                                    | 資金が価格を下回っています。待つか、回収するか、安い部品を選びます。               |
| `資金切れ: 資金が0を超えるまで、配置もアップグレードも採用もできません。` | 資金が0以下です。先にノードを売るか売上を回収します。                              |
| `<Component> には <Research> が必要です。`                                | コンポーネントがロックされています。**リサーチ**を開き、示された項目を研究します。 |
| `先にそのリージョンを開いてください。`                                    | 開いていないリージョンに置こうとしました。                                         |
| `<Mutator>: <Component> は使えません。`                                   | 会社のミューテーターがそのコンポーネントを禁止しています。                         |

ドックのロックされた行は行き止まりではありません。1つをクリックすると、ドックの上の帯がリサーチとそのインサイト価格を示し、**リサーチ**ボタンで開けます。帯は受け取るか閉じるまで待ちます。赤い行は同じ警告を1歩早く示します。トーストが価格を繰り返すので、ボードをクリックする前に読みます。
