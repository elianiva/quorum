ノードカードは、ノードが受け取るもの、どれだけ埋まっているか、何を送り出すかを示します。まず**負荷**の行を読みます。ノードが限界にどれだけ近いかが分かります。

::Component{id="server"}

![ボード上のノードカード。ヘッダー、行、下部のボタン。](/play/node-card.png)

ヘッダー、次に**負荷**のバー、次に下端の下部を見ます。

## ヘッダー

ヘッダーには、コンポーネントのアイコンが入ったメダル、ノードの名前と番号、サイズの点、短い文脈の行が並びます。その行には**×3** のようなコピー数、ゾーンの文字、ほかのリージョンのノードならリージョンと往復時間（**EU 90 ms** など）が入ります。

メダルの角に状態の印が付きます。

| 形   | 意味                                                                            |
| ---- | ------------------------------------------------------------------------------- |
| 点   | ノードは健全です。                                                              |
| 三角 | 容量の70%以上で動いているか、リクエストが行き場を失っているか拒否されています。 |
| 四角 | 容量の90%以上で動いています。                                                   |
| 十字 | ノードが停止しています。                                                        |

トラフィックのないノードには印が出ません。形ごとに色がありますが、形だけで十分です。色の区別がつかないプレイヤーも同じボードを読めます。

## 行

行はコンポーネントによって変わります。次の行はほとんどのノードにこの順で出ます。

| 行             | 示すもの                                                                                                                                                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **流入**       | ノードに届く毎秒のリクエスト数。ノードが一部を落とすと赤くなります。                                                                                                                                                                                 |
| **負荷**       | バーと、**40/s のうち 72%**のようなテキスト。使用率と、その基準になるキャパシティです。**アイドル**はトラフィックがないという意味です。バーは70%から琥珀色、90%から赤になります。`metrics` のリサーチのあとは、行に小さな傾向線が入ります。          |
| **上限**       | `profiling` のリサーチのあとに現れます。ノードを抑えている資源を示します。**CPU 22%**、**RAM 80%**、**ワーカー 20/20**、**ネットワーク 40%**、**CPU クレジット**、**接続 90/100**、**ディスク IOPS**、**スループット**、**余裕あり**のいずれかです。 |
| スタックの行   | アプリサーバーとワーカーはランタイムとフレームワークを示します。                                                                                                                                                                                     |
| **レイテンシ** | ノードが加える時間。`percentiles` のリサーチがあると**12 ms · p99 40 ms**と表示されます。                                                                                                                                                            |
| **流出**       | リンクへ送り出す毎秒のリクエスト数。受け取るリンクのないリクエストがあると、行が赤い**行き場なし**に変わり、失われるレートが出ます。                                                                                                                 |

追うべきは**行き場なし**の行です。受け取る外向きのリンクがないノードに届いたリクエストはエラーになるので、ノードを受け取れるものにリンクします。

**負荷**のバーが低いだけでは分かりません。隣の**上限**を読みます。**負荷**が40%でも**接続**で頭打ちになっているノードはあります。

一部のコンポーネントは行を自前のものに差し替えます。

- **ユーザー**は**ユーザー**、**Apdex**、**リクエスト**を示します。
- **決済**は**売上**と、回収を待つ資金である**引き出し**を示します。Stripe のリサーチのあとは行が**Stripe**になります。
- **アナリティクス**は**サンプリング**、**保持**、どのタップにも届かないトラフィックがあるときの**未分類**、そして上位のインサイトの行を示します。
- **データベース**は**エンジン**、**ボリューム**、**接続**を示します。
- **キャッシュ**は**ヒット率**を示します。

## ボトルネックの枠線

シミュレーションは、いまキャパシティを足すと最も売上が増えるノードを1つ選びます。そのノードに琥珀色の脈打つ枠線が付きます。名前は出ないので、原因を探すにはカードを読みます。

枠線を見ます。そのカードの**負荷**のバーはたいてい琥珀色か赤で、**上限**の行が直すものを示します。

ノードを直すと枠線は移ります。新しいノードへ移れば、前のノードはもう限界ではありません。どのノードにも付かなければ、売上を抑えているものはありません。枠線は資金が最も効く場所を示すので、ほかの場所でサイズを買う前に確認します。

## 下部

カードの下端の帯はボタンです。働きはノードによって変わります。

| 下部のテキスト       | 働き                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| サイズ名と価格       | 次のサイズを買います。押し続ける必要があります。                           |
| **サンプル**と価格   | アナリティクスの場合、サンプリングを増やします。押し続ける必要があります。 |
| **回収**と金額       | 決済の場合、引き出しを回収します。1クリックで済みます。                    |
| **引き出しは空です** | 回収するものがありません。ボタンはオフです。                               |
| **自動で回収**       | Stripe のリサーチ後の決済です。                                            |
| **最大サイズ**       | これ以上ノードを大きくできません。                                         |
| **置き換え**と価格   | ノードが止まりました。払って戻します。                                     |

### 押し続けて買う

サイズは資金を食うので、カードは意思を確かめます。下部を押し、塗りがボタンを横切るまで押し続けます。およそ0.6秒で購入が成立し、カードが短い光を放ちます。

素早いクリックでは何も買えないので、塗りが動く間はポインタを押したままにして、ボタンの外へドラッグすると取り消せます。最初の購入のあとも押し続けると、手を離すか、資金が尽きるか、最大サイズに達するまで、0.25秒ごとに次のサイズを買います。**資金切れ: 資金が0を超えるまで、配置もアップグレードも採用もできません。**のような拒否は、トースト1つで押し続けるのを終わらせます。

インスペクタの**大きくする**ボタンは別です。1クリックで1サイズを買い、押し続けると繰り返します。[インスペクタ](/play/the-inspector)を参照してください。
