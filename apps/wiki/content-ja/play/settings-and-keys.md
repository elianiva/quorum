何も開いていない状態で `Esc` を押すとメニューが出るので、**設定**を選びます。タイトル画面では**設定**はタスクバーにあります。設定は5つの節に分かれます。**サウンド**、**プレイ**、**表示**、**プライバシー**、**セーブ**です。パネルは5つを一度に並べ、タイトル画面は1節ずつ示して `←` と `→` で移動します。変更はどれもすぐに効きます。

![設定のパネル](/play/settings.png)

## 設定

| 設定                                         | 効果                                                                                               |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **音量**                                     | 効果音のミックスの大きさを決めます。タイトル画面では `←` と `→` で決めます。                       |
| **消音**（`M`）                              | すべての音を切ります。サウンドを戻すまでスライダーは休みます。                                     |
| **イージーモード**                           | 一時停止と速度の操作を加え、**SEV1・SEV2で一時停止**を現します。                                   |
| **SEV1・SEV2で一時停止**                     | 重大なインシデントが始まったときに時計を止めます。既定はオフです。                                 |
| **ウィンドウがフォーカスを失ったら一時停止** | タブやウィンドウを切り替えたときに止めます。既定はオンです。                                       |
| **動きを減らす**                             | アニメーションを減らします。オフのときはシステムの設定に従います。                                 |
| **文字サイズ150%**                           | インターフェースの文字を大きくします。ボードのカードはズームで拡大します。                         |
| **ダークモード**                             | 暗いインターフェースを使います。                                                                   |
| **言語**                                     | インターフェースの言語を選びます。                                                                 |
| **エージェントアクセス**                     | ローカルのエージェントがリレー経由でゲームを読めるようにします。読むことだけです。既定はオフです。 |
| **匿名の利用データを共有**                   | 匿名の利用データを送ります。オフで収集を止めます。既定はオンです。                                 |
| **プライバシーポリシー**                     | ポリシーを新しいページで開きます。                                                                 |
| **セーブをテキストでコピー**                 | この会社を `QSV1:` で始まるテキストとしてコピーします。                                            |
| **セーブをファイルに保存**                   | この会社をその名前のファイルとして保存します。`quorum-acme-cloud.txt` などです。                   |
| **セーブファイルを読み込む**                 | セーブファイルから会社を読み込みます。                                                             |
| **セーブを貼り付け**                         | その `QSV1:` のテキストを貼るよう求め、読み込みます。                                              |
| **状態をJSONでコピー**                       | バグ報告のために、ゲームの状態全体をコピーします。                                                 |

設定は会社ではなくブラウザに属します。**セーブファイルを読み込む**を使う前に[会社を別のブラウザへ移す](/guides/move-a-company)を、利用データが何を持つかは[プライバシーのページ](/about/privacy)を読んでください。

メニューには**再開**、**コマンド**、**設定**、**ルーム**、エグジットできるときの**会社を終了**、そして**タイトル画面**も入ります。**再開**と `Esc` はボードへ戻ります。会社をオンラインにする前に[ルームで遊ぶ](/play/rooms)を読んでください。

**コマンド**はボードの上に重なるパレットです。macOS では `Cmd+K`、ほかの環境では `Ctrl+K` で開き、入力で絞り込み、`Enter` で強調された行を実行します。すべての行動を、それを走らせるキーとともに並べます。置く部品、ノードの変更、リサーチ、パネル、ボードの表示、選択、リージョン、設定です。開いている間は時計を止め、`Esc` で閉じます。

## キー

キーはボードにいて欄に入力していないときに働きます。`Alt` を押している間は働きません。`Esc` はすべてを閉じるのではなく一番上の層を1つずつ閉じるので、何も開いていないときにもう一度押すとメニューが出ます。

![ツールバーの速度ボタン](/play/speed-controls.png)

### パネル

| キー               | 行動                                                     |
| ------------------ | -------------------------------------------------------- |
| `R`                | リサーチ。表示されてからです                             |
| `T`                | チーム。表示されてからです                               |
| `D`                | ダッシュボード。`metrics` のあとです                     |
| `P`                | プレイブック。最初のエグジットのあとです                 |
| `I`                | 受信箱                                                   |
| `$`                | クラウドの請求: 支出、売上、利益率。ボタンはありません。 |
| `H` か `?`         | 遊び方                                                   |
| `Esc`              | 一番上の層を閉じる。何も開いていなければメニューを開く   |
| `Cmd+K` / `Ctrl+K` | コマンド: 領域ごとにまとめたすべての行動                 |

### 時計と表示

| キー           | 行動                                    |
| -------------- | --------------------------------------- |
| `Space`        | 一時停止または再開                      |
| `S`            | 次の速度: 0.5×、1×、3×、10×、そして戻る |
| `Z`            | 元に戻す                                |
| `Shift+Z`、`Y` | やり直す                                |
| `Shift+T`      | 役割ごとに整える                        |
| `Shift+F`      | ボードに合わせる                        |
| `F`            | 全画面                                  |
| `M`            | 消音                                    |
| `C`            | 決済の引き出しを回収                    |

### 建設

| キー                      | 行動                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `1` から `7`              | その建設グループを開く: Edge、コンピュート、データ、メッセージング、プラットフォーム、可観測性、マネージド。使えるグループだけを、表示の順に数えます。 |
| グループ内の `1` から `9` | 開いた一覧からその部品を選ぶ                                                                                                                           |
| `Enter`                   | 部品を手に持っているとき、次の空き位置に置く                                                                                                           |
| `Esc`                     | 部品を捨てる                                                                                                                                           |

### 選択と移動

| キー                      | 行動                                                                           |
| ------------------------- | ------------------------------------------------------------------------------ |
| 矢印キー                  | その方向で最も近いノードを選択する                                             |
| `Enter`                   | 選択中のノードのインスペクタを開く                                             |
| `L`                       | 選択中のノードからリンクを始める                                               |
| 行き先での `L` か `Enter` | リンクを完成させる。`Esc` で取り消す。                                         |
| `U`                       | 選択中のノードの次のサイズを買う                                               |
| `Shift+矢印`              | 選択を微移動する                                                               |
| `Ctrl/Cmd+A`              | すべて選択                                                                     |
| `Ctrl/Cmd+C`、`X`、`V`    | コピー、切り取り、貼り付け                                                     |
| `Ctrl/Cmd+D`              | 複製                                                                           |
| `Delete`、`Backspace`     | 選択を売却するか、選択中のリンクを切る。売却は先に尋ね、`Enter` で確定します。 |

矢印キーと `Enter` はボードにフォーカスがあるときだけ働き、パネルにある間は働きません。
