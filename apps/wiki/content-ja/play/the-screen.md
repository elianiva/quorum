ボード画面には5つの領域があります。左上の HUD、右上のツールバー、下の建設ドック、右のインスペクタ、そしてそのすべての奥にあるボードそのものです。右下には丸い受信箱ボタンがあります。それ以外はすべて上に開くパネルです。

![各領域に名前を付けたボード画面。HUD、ツールバー、ボード、建設ドック、インスペクタ、受信箱ボタン。](/play/screen.png)

_まず左上の HUD を探します。次に数字をたどります。HUD が会社の調子を示し、ボードがその理由を示します。_

ゲームは最初、わずかな操作しか見せず、必要になるにつれて残りを加えます。画面にない操作はまだ獲得していません。設定で隠されているのではありません。

## HUD

HUD は左上のカードです。いま重要な数値を1行ずつ示します。

![会社の開始時の HUD。資金、ユーザー、Apdex、レイテンシ。](/play/hud.png)

_時代の名前の下の4行を見ます。それぞれに名前、値、その横の小さな注記があります。_

**見出しの行**には3つが入ります。

- **メニュー**ボタン。ラベルは**メニュー (Esc)**です。ゲームのメニューを開きます。
- 時代の名前。たとえばガレージです。
- カレンダー。たとえば `D1 14:01` です。実時間の1秒がカレンダーの1分です。

見出しの下のバーは、ユーザーが次の[資金調達ラウンド](/explanation/progression)に近づくにつれて満ちます。満ちると、その場所に次の時代の名前と**のオファー**が付いたボタンが現れます。上場前の最後の段階では**IPO**と表示されます。

**行**は次のように読みます。

| 行             | 値                               | その横                             | クリック                                   |
| -------------- | -------------------------------- | ---------------------------------- | ------------------------------------------ |
| **資金**       | 使えるお金                       | 毎秒の純増減、そのあとに残りの月数 | 資金が足りないときだけダッシュボードを開く |
| **ユーザー**   | 会社を使っている人               | 直近の変化を示す ▲ か ▼            | **離脱の理由**を開く                       |
| **Apdex**      | 直近1時間の満足度。0 から 1      | `/` と時代の目標                   | なし                                       |
| **エラー**     | 失敗するリクエストの割合         | なし                               | なし                                       |
| **レイテンシ** | リクエストに答えるまでの平均時間 | なし                               | なし                                       |

連鎖として読みます。**Apdex** が目標以上なら**ユーザー**が増えます。**ユーザー**が増えるほどリクエストが増え、ノードの負荷が上がります。ノードが**キャパシティ**を使い切ると**Apdex** が下がり、**ユーザー**が離れます。赤い**Apdex** の横に**ユーザー**の ▼ があれば、いまボトルネックが痛めつけています。

各行の細部です。

- **資金**は0を下回ると赤くなります。残り月数のあとの注記は、30日の月で `mo` です。資金が0でも売却とリサーチはできますが、配置もアップグレードもできないので、赤い**資金**は配置が拒否されるという意味です。
- **ユーザー**は直近の傾向での変化を示し、増えた総数ではありません。
- **Apdex** は目標を下回ると赤くなります。行にホバーすると目標の働きが読めます。
- **エラー**は最初にリクエストが失敗したときに現れるので、行が出たら原因のノードを開きます。ホバーで原因が出ますが、それは構造化ログをリサーチしたあとだけです。それまではホバーに**原因を見るには構造化ログをリサーチ**と出ます。
- **レイテンシ**はパーセンタイルをリサーチすると**p99**になります。平均はその横に `μ` 付きで出ます。[p99 を読む](/guides/read-p99)を参照してください。

あとの行は該当するときに現れます。**SLO**の行、**SLA**の行、走っている研究を示すインサイトのカード、チームのカードです。[リサーチとチームのパネル](/play/research-and-team)が扱います。

## ツールバー

ツールバーは右上の帯です。ボタンにホバーすると名前とキーが読めます。

| ボタン                     | キー           | 働き                                                                                |
| -------------------------- | -------------- | ----------------------------------------------------------------------------------- |
| **リサーチ**               | `R`            | リサーチツリーを開きます。バッジが開始できる研究の数を数えます。                    |
| **チーム**                 | `T`            | チームのパネルを開きます。琥珀色の点はバックログが空という意味です。                |
| **プレイブック**           | `P`            | 保存した設計の部品を開きます。最初のエグジットのあとに現れます。                    |
| **エグジット**             | なし           | シリーズ A から、エグジットのパネルを開きます。獲得するレガシーを示します。         |
| **ダッシュボード**         | `D`            | グラフを開きます。`metrics` のリサーチが必要です。                                  |
| **遊び方**                 | `H`            | 6つの中心的な行動とキーの一覧を開きます。                                           |
| **用語集**                 | なし           | wiki のエンジニアリング用語を開きます。最初のトレードオフのカードのあとに現れます。 |
| **元に戻す**と**やり直す** | `Z`、`Shift+Z` | ボードでの最初の操作のあとに現れます。                                              |
| **一時停止**か**再開**     | `Space`        | 時計を止め、再び動かします。                                                        |
| **速度**                   | `S`            | 速度を `1×` のように示します。押すたびに次へ進みます。                              |
| **役割ごとに整える**       | `Shift+T`      | ノードを役割の列に並べます。                                                        |
| **ボードに合わせる**       | `Shift+F`      | すべてのノードが見えるようにズームと移動をします。                                  |
| **全画面**                 | `F`            | 全画面を切り替えます。                                                              |

最初は**遊び方**、**一時停止**、**速度**、ボードの3つのボタンが見えます。残りは役に立つようになると現れるので、**リサーチ**、**チーム**、**元に戻す**のボタンがないのはまだ獲得していないという意味です。スマートフォンでは**その他**のボタンに同じ行動が入ります。[時計、元に戻す、セーブ](/play/clock-undo-saves)が速度を扱います。[設定とキー一覧](/play/settings-and-keys)がすべてのキーを並べます。

## 建設ドック

建設ドックは下のグループのアイコンの列です。コンポーネントを置く方法です。

![会社の開始時の建設ドック。4つのグループのアイコンと、開いた Edge の一覧。](/play/dock.png)

_下の列のアイコンを見ます。それぞれがコンポーネントのグループです。その上の一覧が、開いているグループの中身です。_

グループは7つあり得ます。**エッジ**、**コンピュート**、**データ**、**メッセージング**、**プラットフォーム**、**可観測性**、**マネージド**です。グループは、置けるものか次に解放されるものを含むときだけ出ます。新しい会社では4つ出ます。アイコンにホバーすると、**エッジ (1)** のように名前と番号が読めます。

[コンポーネントを置く](/play/place-components)がドックを1歩ずつたどります。部品を手に持っている間、ドックにはその名前、**ボードをクリック**、X ボタンが出ます。同じバーの場所には、ノードを選択すると選択バーが、売却を求めると売却バーが出ます。それらは[移動、選択、コピー、売却](/play/move-and-select)にあります。

## ボード

ボードはすべての奥にある面です。ノードはその上のカードで、リンクがそれらをつなぎます。

- 空き領域をドラッグすると表示が動きます。
- マウスホイールで4分の1から1.5倍までズームします。タッチ画面ではピンチです。
- 空き領域をクリックすると選択を解除します。

遠くでは、カードは行を失い、やがて小さなチップに縮みます。**ボードに合わせる**で設計全体を見て、カードを読みたいときはズームインします。[ノードカードを読む](/play/read-a-node-card)が1枚のすべての行を説明します。

## インスペクタ

インスペクタは右のパネルです。ノードを選ぶと開き、X ボタンか `Esc` で閉じます。いまの数値、赤か琥珀色の枠の警告、そのノードのオプションを示します。[インスペクタ](/play/the-inspector)がその節を扱います。

## 受信箱ボタン

右下の丸いボタンが**受信箱**（`I`）です。数字のバッジが未読のメールを数えます。対応を待つメッセージがあると、バッジが赤くなりボタンが脈打ちます。[メール、ダッシュボード、用語集](/play/mail-dashboard-glossary)がフォルダを説明します。

## 上の帯とトースト

ボードの上端に沿って、ゲームはすぐ見るべきものを置きます。複数のリージョンで動かすとリージョンのタブ、何かが壊れるとページャーとインシデントの帯、そして変更のピルです。変更のピルは最後の変更に**アプリサーバーをリサイズ**のような名前を付け、コスト、レイテンシ、エラーへの影響を元に戻すボタン付きで示します。

トーストと呼ばれる短いメッセージは、ゲームが行動を断るときや確定するときに現れます。断りは素の文で出て、この節の各ページは自分が起こし得るものを引用します。
