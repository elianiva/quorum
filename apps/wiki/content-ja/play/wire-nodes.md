リンクを作るには、ノードのカード右端の出力ポートを押し、別のノードへドラッグして、そのカードの上で離します。するとリクエストが1つ目のノードから2つ目へ流れます。リンクには向きがあり、外へ出るリンクのないノードは何も渡しません。そのためトラフィックをまだ受け取るノードは赤い**行き場なし**の行を示し、そのリクエストをエラーとして数えます。例外はデータのノードとアナリティクスです。

## 出力ポート

どのカードにも左端に入力ポートがあり、リンクはそこへ届きます。トラフィックを送り出すカードには右端にも出力ポートがあり、**流出**の行と同じ高さで、リンクはそこから出ます。[データベース](/components/database)の出力ポートの用途は1つです。書き込みログを読む[CDC コネクタ](/components/cdc)へリンクすることです。リクエストは何も渡しません。

リンクを始めるのは出力ポートだけです。入力ポートを狙うことはありません。行き先のカードの上ならどこで離しても十分です。カードのほかの部分を押すとカードのドラッグになるので、ポートを狙います。

## リンクを作る

1. 両方のノードを置きます。[コンポーネントを置く](/play/place-components)を参照してください。
2. 送る側のノードの出力ポートへポインタを動かします。カーソルが変わります。
3. 押してドラッグします。ポインタに沿って線が付いてきます。
4. 受け取る側のノードの上までドラッグします。そのカードが光ります。
5. 離します。リンクが現れ、リクエストの帯がそれに沿って流れ始めます。

リンクが通れば、上の変更のピルが**アプリサーバーをデータベースにリンク**のように名前を付けます。`Z` で元に戻せます。

空き領域の上、または始めたノードの上で離すと、線は元に戻り何も起きません。そのときゲームは何も表示しません。

まだ PostgreSQL を自分の箱で動かしているアプリサーバーからデータベースへの最初のリンクは、PostgreSQL を移します。ゲームは**Postgres をアプリサーバーから専用のデータベースへ移しました。**と言います。プーラーやキャッシュへのリンクでも同じことが起きます。

## リンクに必要なもの

次のすべてが成り立つとき、リンクは許されます。

- 送る側のノードが何かを送り出す。ユーザー、アプリサーバー、ロードバランサーは送り出します。データベース、アナリティクス、決済は送り出しません。
- 受け取る側のノードが、送る側の送るリクエスト種別を少なくとも1つ受け取る。データベースはクエリを受け取り、ページビューは受け取りません。
- 2つのノードが違い、リンクが存在せず、ループを作らない。
- 送る側に空きのリンクがある。ユーザーは1本で、いくつかのコンポーネントは本数が決まっています。

向きは最初のルールから決まるので、リンクはアプリサーバーからデータベースへ通り、データベースからアプリサーバーへは通りません。データのノードは送り出さないからです。

アナリティクスは最初と最後のルールの例外です。決済以外のどのノードでもリンクすれば、そのノードが何を送るかに関係なく、そのトラフィックをサンプリングします。このリンクは空きのリンクを消費しません。サンプリングするのは届いたトラフィックだけなので、トラフィックのない送り手からは何も得られません。決済はリンクがまったく要りません。売上はひとりでに引き出しへ届きます。

## ゲームが断るとき

断りはトーストで出ます。リンクは作られず、料金もかかりません。

| メッセージ                                                                           | 原因                                                                            |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| `すでにリンクされています。`                                                         | リンクが存在します。選択すると見えます。                                        |
| `<Receiver> は <kinds> を受け取ります。<Sender> は <kinds> を送ります。`             | 受け手が送り手の送るものを1つも受け取りません。どちらの一覧もトーストに出ます。 |
| `<Sender> は何も送り出しません。アナリティクスにリンクするとサンプリングできます。`  | 送り手に出力がありません。データベースや決済などです。                          |
| `<Receiver> に入力がありません。`                                                    | そこへは何も送れません。ユーザーが例です。                                      |
| `<Sender> は <n> 本のリンクを持てます。`                                             | 送り手が持てるリンクをすべて使っています。                                      |
| `ドメインは1つのホストに解決されます。先に DNS かロードバランサーを置いてください。` | ユーザーからの2本目のリンクです。                                               |
| `そのリンクはループを作ります。`                                                     | 受け手がほかのリンクを通じてすでに送り手へ戻っています。                        |
| `<Sender> にはサンプリングするトラフィックがありません。`                            | 決済かアナリティクスをアナリティクスにリンクしました。                          |

制御のコンポーネントには自前のメッセージがあります。

- `アプリサーバーかワーカーを <Component> にリンクしてください。`は、オートスケーラーや Kubernetes クラスターに別のものをリンクしたときに出ます。
- `<Sender> にはすでに <Component> があります。`は、アプリサーバーかワーカーにオートスケーラーやクラスターがすでにあるときに出ます。
- `データベースを <Component> にリンクしてください。書き込みログを読みます。`は CDC コネクタで出ます。

もう1つの断りの文、`別々のノードを2つリンクしてください。`は、ノード自身へのリンクを扱います。ポインタでは決して出ません。始めたカードの上で離すと取り消されるからです。

## リンクを選択、編集、切断する

リンクのクリックは選択です。決して切断しません。

1. リンクにホバーします。カーソルがポインタになります。
2. クリックします。選択中のノードは選択が外れ、リンクの中央に**×**のバッジが出ます。
3. 切るには**×**のバッジをクリックするか、`Delete` か `Backspace` を押します。
4. 残すには `Esc` を押すか、空き領域をクリックします。

リクエストの帯が止まり、リンクが消えるのが見えます。変更のピルは2つのノード名とともに**切断**と出て、`Z` でリンクが戻ります。右クリックでもリンクを選択でき、タッチ画面ではタップで選べます。

`Delete` を押す前に何が選択されているか確かめます。ノードを選択していると `Delete` はそのノードの売却を尋ねるので、先にリンクをクリックします。

リンクに専用のパネルはありません。設定は送る側のノードにあります。送り手を選択し、インスペクタの**呼び出し**の節を開きます。そこから出る各リンクについて、次を設定できます。

- **1 s**、**5 s**、**30 s**のタイムアウト。
- リトライ: **リトライなし**、**3回リトライ**、**バックオフ**。
- **ブレーカーなし**か**ブレーカー**。
- **バルクヘッドなし**か**バルクヘッド**。
- **1コピー**か**ヘッジ**。

**呼び出し**の節にはタイムアウトとリトライのリサーチが必要です。その先の各オプションにはそれぞれのリサーチが要ります。[インスペクタ](/play/the-inspector)がその節を説明します。

## キーボードでリンクする

キーボードでもリンクを作れます。フォーカスがテキスト欄ではなくボードにある必要があります。

1. 送る側のノードを選択します。クリックするか、矢印キーで動かします。
2. `L` を押します。ゲームが送り手を覚えます。
3. 受け取る側のノードが選択されるまで矢印キーを押します。各矢印はその方向で最も近いノードを選びます。
4. `Enter` か `L` をもう一度押します。リンクが作られるか、トーストが理由を告げます。

断られたあとも送り手は覚えられたままなので、別のノードを試します。忘れさせるには `Esc` を押します。

## 試してみる

下の練習ボードで3本のリンクを作ります。ユーザーからアプリサーバー、アプリサーバーからデータベース、アプリサーバーからアナリティクスです。それぞれの出力ポートから次のカードへドラッグします。そのあと1本のリンクを選択し、**×**のバッジで切って、もう一度作ります。

下にロードバランサーが2つ待っています。1つ目を2つ目にリンクし、そのあと2つ目から1つ目へドラッグします。ゲームは**そのリンクはループを作ります。**と断り、それを読むと最後の目標に印が付きます。ここですることは会社に何も触れません。
